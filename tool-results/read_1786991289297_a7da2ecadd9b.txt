    44→  - `text-gray-900` → `text-foreground`

    46→  - `text-gray-600` / `text-gray-500` → `text-muted-foreground`

    48→  - `border-gray-200` / `border-gray-100` → `border-border`

   279→## Phase 5 Changes (Task 5b — AI Course Generation)
   280→
   281→### Overview
   282→Replaced the placeholder/mock section generation in the Create Course page with real AI-powered content generation using `z-ai-web-dev-sdk` (GLM-4-Flash LLM).
   283→
   284→### 1. New API Route: `/api/generate-content` (route.ts)
   285→- **POST endpoint** accepting `{ topic, prompt, language? }`
   286→- Uses `z-ai-web-dev-sdk` LLM (GLM-4-Flash) on the server side only
   287→- System prompt instructs the AI to generate structured slide content as a JSON array
   288→- Supports both English and Chinese content generation
   289→- Generates 5-7 slides per section: 1 title slide, 3-5 content slides (mix of content/list/table/code types), 1 quiz slide
   290→- Quiz slide includes 4 answer options with the correct answer marked via `icon: "check"`
   291→- Robust JSON parsing: strips markdown code block wrappers, finds JSON array in response, validates structure
   292→- Fallback validation: ensures quiz has exactly 4 options, at least one correct answer, all slides have titles and valid types
   293→- Graceful error handling with user-friendly error messages
   294→
   295→### 2. Updated Create Course Page (`create-course-page.tsx`)
   296→- Replaced `handleGenerateSection` from `setTimeout` + `generatePlaceholderSlides` to async `fetch("/api/generate-content")`
   297→- Sends `{ topic: sectionName, prompt: sectionPrompt, language: sectionLanguage }` to the API
   298→- Parses AI response as `SlideContent[]` and populates the section draft fields
   299→- Loading state preserved via existing `generating` state + `Loader2` spinner in the Generate button
   300→- Toast notifications on success/error using `sonner`
   301→- No changes to UI layout or component structure — only the generation logic was swapped
   302→
   303→### Design Decisions
   304→- **Bilingual prompts**: System and user prompts are fully tailored for English vs Chinese, ensuring natural-sounding output
   305→- **Schema-first prompting**: The system prompt includes the exact SlideContent type schema so the LLM outputs conformant JSON
   306→- **Defensive parsing**: Multiple layers of JSON extraction (strip markdown, find array boundaries, validate/fallback) to handle LLM output variability
   307→- **Quiz correctness**: Guarantees exactly 4 quiz options with a marked correct answer, matching the interactive QuizSlide component expectations
   308→- **No new dependencies**: Uses existing `z-ai-web-dev-sdk` and project patterns
