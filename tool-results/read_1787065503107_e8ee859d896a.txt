   128→   128→### B. HTML Sanitizer (`src/lib/sanitize.ts`)
   129→   129→
   130→   130→Use **DOMPurify** (isomorphic-dompurify for SSR compatibility) with strict config:
   131→   131→
   132→   132→**ALLOWED_TAGS**: `div, section, article, header, footer, main, h1-h6, p, span, ul, ol, li, a, img, strong, em, b, i, u, br, hr, table, thead, tbody, tr, td, th, blockquote, code, pre`
   133→   133→
   134→   134→**ALLOWED_ATTR**:
   135→   135→- Global: `class, id`
   136→   136→- `<a>` only: `href` (validated: must start with `https://`)
   137→   137→- `<img>` only: `src, alt, width, height` (src validated: must match ImageKit domain)
   138→   138→
   139→   139→**EXPLICITLY FORBIDDEN**: `script, style, iframe, object, embed, form, input, button, link, meta, base, noscript, svg`
   140→   140→
   141→   141→**No inline `style=""`** — Tailwind classes only. Strip all `on*` event handler attributes globally.
   142→   142→
   143→   143→**URL restrictions**:
   144→   144→- `href`: `https://` only, no `javascript:` or `data:` schemes
   145→   145→- `img src`: Must match `IMAGEKIT_URL_ENDPOINT` domain — reject any other domain

   147→   147→### C. AI Client — z-ai-web-dev-sdk Streaming
   148→   148→
   149→   149→**File**: `src/lib/ai.ts`
   150→   150→
   151→   151→```typescript
   152→   152→// Wrapper that uses z-ai-web-dev-sdk with streaming
   153→   153→import ZAI from 'z-ai-web-dev-sdk';
   154→   154→
   155→   155→export async function streamSlideHtml(
   156→   156→  systemPrompt: string,
   157→   157→  userPrompt: string,
   158→   158→): Promise<ReadableStream<Uint8Array>> {
   159→   159→  const zai = await ZAI.create();
   160→   160→  const stream = await zai.chat.completions.create({
   161→   161→    messages: [
   162→   162→      { role: 'assistant', content: systemPrompt },
   163→   163→      { role: 'user', content: userPrompt },
   164→   164→    ],
   165→   165→    stream: true,
   166→   166→    thinking: { type: 'disabled' },
   167→   167→  });
   168→   168→  // stream is ReadableStream<Uint8Array> (SSE format)
   169→   169→  return stream;
   170→   170→}
   171→   171→
   172→   172→// Non-streaming variant for outline generation
   173→   173→export async function generateOutline(topic: string, prompt: string): Promise<string> {
   174→   174→  const zai = await ZAI.create();
   175→   175→  const completion = await zai.chat.completions.create({
   176→   176→    messages: [
   177→   177→      { role: 'system', content: OUTLINE_SYSTEM_PROMPT },
   178→   178→      { role: 'user', content: prompt },
   179→   179→    ],
   180→   180→    thinking: { type: 'disabled' },
   181→   181→  });
   182→   182→  return completion.choices[0]?.message?.content ?? '';
   183→   183→}
   184→   184→```

   186→   186→### D. API Endpoints
   187→   187→
   188→   188→#### 1. `POST /api/generate-outline` — Outline Generation (non-streaming)
   189→   189→
   190→   190→**Request**: `{ topic: string, prompt: string, language?: string }`
   191→   191→**Response**: `{ success: true, data: { title: string, sections: { title: string, summary: string }[] } }`
   192→   192→
   193→   193→Uses z-ai-web-dev-sdk non-streaming to generate a course outline. The instructor can review/edit before proceeding.
   194→   194→
   195→   195→#### 2. `POST /api/generate-slide-html` — Slide HTML Streaming
   196→   196→
   197→   197→**Request**: `{ sectionTitle: string, prompt: string, language?: string }`
   198→   198→**Response**: SSE stream with events:
   199→   199→```
   200→   200→event: slide_start
   201→   201→data: {"sectionTitle": "..."}
   202→   202→
   203→   203→event: chunk
   204→   204→data: {"html": "<div class=\"...\">..."}
   205→   205→
   206→   206→event: chunk
   207→   207→data: {"html": "...more html..."}
   208→   208→
   209→   209→event: slide_complete
   210→   210→data: {"htmlBody": "<full sanitized html>"}
   211→   211→
   212→   212→event: error
   213→   213→data: {"error": "..."}
   214→   214→```
   215→   215→
   216→   216→**Flow**:
   217→   217→1. Build system prompt instructing AI to generate a single HTML document using only Tailwind CSS classes
   218→   218→2. Call `streamSlideHtml()` → get `ReadableStream`
   219→   219→3. Parse SSE chunks, extract text deltas
   220→   220→4. Accumulate HTML string
   221→   221→5. On stream end: sanitize the full HTML via DOMPurify
   222→   222→6. Emit `slide_complete` with sanitized `htmlBody`
   223→   223→
   224→   224→#### 3. `POST /api/generate-slide-inline-edit` — Inline AI Edit
   225→   225→
   226→   226→**Request**: `{ htmlBody: string, instruction: string, slideTitle?: string }`
   227→   227→**Response**: `{ success: true, data: { htmlBody: string } }`
   228→   228→
   229→   229→Non-streaming. Takes existing HTML + natural language edit instruction, returns modified sanitized HTML.
   230→   230→
